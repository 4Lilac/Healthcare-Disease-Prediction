# Healthcare Disease Prediction

## Project Description
A machine learning application that predicts whether a patient's health condition is Normal or Abnormal and estimates BMI using healthcare information.

## Dataset
- Name: 281K Patient Dataset for Multi-Disease Prediction
- Source: Kaggle
- Owner: danishjmeo
- License: CC0 Public Domain

Dataset: https://www.kaggle.com/datasets/danishjmeo/281k-patient-dataset-for-multi-disease-prediction

## Machine Learning Models
- Random Forest Classifier
- Random Forest Regressor

## Final Model Results

Classification:
- Accuracy: 88.26%
- Precision: 87.07%
- Recall: 95.36%
- F1-score: 91.03%
- ROC-AUC: 94.09%

Regression:
- MAE: 1.8325
- RMSE: 2.5757
- R-squared: 86.65%
